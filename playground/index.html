Mohar

A small language where secrets, authority and untrusted input are types, and the compiler signs an authority seal with ML-DSA.

fn main(caps: Caps) {
    let out = caps.console();
    out.println("namaste, duniya");
}

This page is static. The checker lives in the mohar-wasm crate and runs today as a normal Rust library; a browser build of that crate is the next step, not part of the v0.1 tag. Until then:

mohar check hello.mo
mohar review hello.mo

Created by Saddam Malik. The compiler is not a proof, and the post-quantum crates it links have not been independently audited.
